# Повний обсяг розширення

Запит: усі узгоджені фічі на наявному залізі, без фізичних кнопок.
Окремий мобільний застосунок не входить (користувач раніше відмовився від нього на цьому етапі).

- [x] Вебпанель із поточними показами, графіком, API, CSV та діагностикою
- [x] Wi-Fi setup AP, пароль/адреса на OLED, відновлення без кнопок, USB CLI
- [x] Налаштування в NVS, валідація, резервна копія/відновлення
- [x] Історія 24 год, часові мітки, прогалини, пакетний архів flash
- [x] Тренд, витримка попередження, низькі покази, статистика ночі, провітрювання
- [x] SCD40: offset, ASC, висота/тиск, FRC за еталоном, self-test, економний режим
- [x] TEMT6000: майстер калібрування, оцінка шуму, плавна адаптація, експериментальний жест
- [x] Перевірка впливу власної індикації на датчик освітлення
- [x] LED: палітра, gains, preview, гістерезис, gamma, нічний профіль, імпульс попередження
- [x] OLED: сторінки, графік, ніч/провітрювання, sleep/wake, зсув, часткове оновлення
- [x] HomeKit/HomeSpan: CO2/T/RH, підсвітка, сполучення/скидання без кнопок
- [x] MQTT + Home Assistant discovery, availability, reconnect
- [x] Захищене OTA через веб, перевірка образу, відновлення попередньої версії
- [x] Фінальна компіляція ESP32-C3, host-тести та браузерна перевірка
- [x] Документація API, setup, профілю збірки й стендових обмежень

Модель підтверджена: ESP32-C3 Super Mini, USB-порт виявлено. Зміни корпусу, калібрування за реальним
еталоном, вимірювання струму та Apple Home pairing неможливо підтвердити без плати;
прошивка повинна містити відповідні процедури та чітко відображати їхній результат.
